Connect to your ERA5 archive

Run the local reader on the machine containing your data:

cd /data1/tim/era5viewer
./start.sh

Then use this page, or open http://127.0.0.1:8765. The data directory is set in config.json; the default is /data3/ERA5.

For a remote data machine, use an SSH tunnel: ssh -L 8765:127.0.0.1:8765 user@data-machine.
