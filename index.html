Personal configuration Create or load your own JSON file

The shared config.json stays unchanged. Edit these settings, download a personal JSON file, then place it at the chosen path on the data machine. “Load JSON” imports a file into this editor.

Choose a free port on a shared server. The reader listens on loopback by default; reach it through an SSH tunnel.

JSON preview

On the data machine

bash /data1/tim/era5viewer/start.sh

On your computer, for a remote data machine

ssh -N -L 8769:127.0.0.1:8769 user@data-machine

Run the SSH command in a terminal and leave it open. After starting this personal reader, connect to http://127.0.0.1:8769 using the address box above. Loading or downloading JSON prepares settings; it does not reconfigure a running reader.
